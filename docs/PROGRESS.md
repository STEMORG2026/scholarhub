### Reduced-motion guard, and a false premise corrected (twelfth pass, same day, v0.13.0)
- **The outstanding item was wrong.** Since the ninth pass, PROGRESS, ARCHITECTURE and ROADMAP all carried the line "a reduced-motion check — **the hero uses CSS animation** and there is no `prefers-reduced-motion` guard". That premise had never been measured, and it is false. Measured in the running page: **0 of 1,808 elements** report a computed `animation-name` other than `none`. The source contains **0 occurrences** of `animation` and **0** of `@keyframes` across `src/styles.css`, `src/main.jsx` and `index.html`. The only motion in the app is a **0.2s `box-shadow, border` transition on 40 card surfaces**.
- **This is the second instance of the same failure mode in this repository.** The first was "dark mode is fixed" in 0.6.0, which survived four passes because light mode — the default — had never been measured at all. In both cases a claim written in the same confident register as the measured ones turned out to rest on nothing. The lesson is not "measure more"; it is that an *outstanding-item* note is a claim too, and inherits no more authority from being carried forward than from being written fresh.
- **The guard was added anyway, and the reason is documented next to it.** A `prefers-reduced-motion: reduce` block now sits at the end of the stylesheet with a comment recording the measurement, so the next reader does not re-inherit the assumption. It uses `.01ms` rather than `0s` so `transitionend` still fires. It covers the card hover transitions — real motion, worth respecting — and anything animated later.
- **Verified by a reversible control, not asserted.** The rule's presence in the CSSOM was confirmed first (a guard that never reached the stylesheet would pass the same test), then the media query was emulated:

| State | `prefers-reduced-motion` | Perceptible transitions (>50ms) | Max transition duration |
|---|---|---|---|
| Normal | false | **40** | 0.2s |
| Reduce | true | **0** | 0.00001s |

  Resetting the emulation restored 40. The control works in both directions.
- **Two `agent-browser` invocation errors of my own were corrected while doing this.** Media emulation is `agent-browser set media reduced-motion` (not `media`), and `agent-browser set viewport <w> <h>` **does** work — verified 1280×577 → 1024×768. The ninth-pass note that the viewport command "is not actually available" was wrong about the invocation, not the capability. Same error class as the animation claim: a negative result recorded without checking the command was issued correctly.
- **The narrow-screen layout was measured while the viewport was open, and it holds.** At 390×844: no horizontal overflow (`scrollWidth` 390 = `innerWidth` 390), sidebar collapsed to a 64px icon rail, filter selects stacked, cards intact. `.hero-art` bleeds past the right edge by design and is clipped by its panel. So the roadmap's "no slide-out drawer below 850px" is a missing feature, not a broken layout — worth stating, because the old note implied the latter.
- **EESIC was re-checked and the missing field is still missing.** As of 2026-10-07 the admission page carries no closing date; it says the 2027-2029 call "will be published on this section in **October 2026**" — the current month. Its `deadline_notes` now quotes that wording and records the recheck date, and the targeted-region list is transcribed with region numbers (Region 5 Asia included) plus the caveat that the page does not enumerate each region's countries.
- **The link probe's unreachable count turned out not to be reproducible.** I had written "7 of 65 links unreachable" into three documents as a fixed fact, carried forward from pass to pass. Sampling the probe nine times on 2026-10-07 gave **6 unreachable in seven runs and 7 in two**; `HTTP 412` on `www.campuschina.org` appeared every time and `HTTP 503` on `www.nzscholarships.govt.nz` once. Only **`65 checked, 0 dead`** is stable. The rule this restates, from the ninth pass: never quote a figure from a single reading of a signal that can toggle — sample in a loop and report the distribution.

### USA depth: two records open to Nepali applicants (thirteenth pass, same day, v0.14.0)
- Catalog 40 → **42 records**, United States 2 → **4**. This was the region the roadmap had called structurally hard, on the grounds that most US graduate funding is restricted to citizens and permanent residents.
- **The first thing the pass did was check whether the existing records were honest about that restriction — and they were.** NSF GRFP already carries `eligibility.nationality: "U.S. citizens, nationals, or permanent residents"`, and Fulbright already routes applicants to their home-country commission. A catalog that lists a citizen-restricted award without saying so is worse than one that omits it, so this was worth confirming rather than assuming.
- **Knight-Hennessy Scholars (Stanford)** is the strongest find in the region. The programme states it "encourage[s] citizens and residents of all countries to apply", sets **no quotas by discipline, programme or world region**, and requires no institutional endorsement. It funds up to three years of any full-time Stanford graduate degree, including a master's or PhD in civil and environmental engineering: tuition and fees, a living stipend, one annual economy-class round trip, and a one-time relocation stipend. **Verified deadline 6 October 2026** for the 2027 cohort, which closed the day before this pass; the 2028 cycle opens in summer 2027.
- **Two constraints are recorded rather than glossed.** The first bachelor's degree must have been earned **in January 2020 or later** for the 2027 cohort, extended by two years for military service — a genuine filter, not a footnote. And the fellowship funds **up to three years**; for a PhD the department funds the remainder. "Fully funded" would have been the easy phrase and the wrong one.
- **Hubert H. Humphrey Fellowship** is a non-degree Fulbright for mid-career professionals: ten to twelve months at a U.S. host university with a professional affiliation placement. **Nepal is confirmed on the 148-country eligibility list**, under South and Central Asia, administered by the Binational Fulbright Commission. It requires five years of full-time professional experience, and the engineering-adjacent fields sit under the Sustainable Lands impact area — natural resources and environmental policy, and urban and regional planning. **Its Nepal page was reachable only over plain HTTP**; the HTTPS host fails outright, which is why the deadline could not be pinned and the record uses `deadline_notes` instead.
- **Two candidates were examined and left out on evidence, not on convenience.** The **Aga Khan Foundation International Scholarship Programme** names Afghanistan, Bangladesh, India and Pakistan among its countries but **not Nepal**, and presents the list as examples rather than exhaustive — suggestive, not conclusive, and an eligibility question that cannot be settled is not a basis for a record. The **ANSO-CAS-TWAS/UNESCO PhD Scholarship** is a genuinely strong lead — up to 40 PhD places a year for developing countries, CNY 6,000–7,000 a month with tuition and insurance waived, "Engineering Sciences" among its ten fields — but the page consulted **does not name Nepal**, delegates eligibility to TWAS's developing-country list, and describes a closed call. It is recorded as a lead for a dedicated check rather than guessed at.
- **The `Non-degree` track now holds three records across two countries** — the two New Zealand short-term schemes and Humphrey — and Phase 1 in `docs/ROADMAP.md` now names it as its own line, which the roadmap had flagged as missing.
- Verified: `npm test` 0 errors / 5 warnings (unchanged); build clean; link probe **70 checked, 0 dead**, all five new URLs returning `OK [200]`; browser confirmed **42 opportunities**, the USA filter returning **4**, and both new cards rendering.

### China PhD depth: the ANSO-CAS-TWAS lead resolved (fourteenth pass, same day, v0.15.0)
- Catalog 42 → **43 records**, China 4 → **5**. This pass took the ANSO-CAS-TWAS/UNESCO PhD Scholarship — carried as a lead in the thirteenth pass rather than guessed at — and resolved it on evidence.
- **Nepal's eligibility was the blocker, and it is now settled.** The scholarship page delegates eligibility to TWAS's developing-country list without naming countries, so the list itself was read: **Nepal is entry 088 of 138**. That one fact is what turned the lead into a record.
- **The record carries no deadline, and that is a decision rather than an omission.** TWAS labels the call "The call is closed"; the 2026 cycle opened 15 October 2025 and closed 31 January 2026, and that is the only cycle any page describes. The 2027 call had not been published when this record was checked on 2026-10-07. The pattern across cycles is a mid-October opening, but a pattern is not a date — writing the expected date into `deadline` would have been a fabrication wearing a citation. `deadline` is `null`, `status` is `closed`, and `deadline_notes` carries the cycle, the pattern and a re-check prompt.
- **A freshly published page can still describe a closed call.** A CAS-ANSO Scholarship (Degree Program) call page published on **22 July 2026** was checked and still reproduces the 15 October 2025 – 31 January 2026 window. Publication date is not cycle freshness.
- **The record does not claim civil engineering, because the source does not.** The scheme names ten umbrella fields and "06-Engineering Sciences" is the only engineering one; civil engineering, environmental engineering and materials science are not named as separate disciplines, and the host route is UCAS/USTC/CAS institutes rather than a named civil-engineering faculty. `program_field` carries `["Engineering Sciences"]` — the exact named field — and `eligibility.other` sends the applicant to a specific host supervisor. "Civil Engineering" would have matched the four existing China records, and would have been invented in order to match.
- **The CAS-TWAS President's Fellowship was excluded again, on the same evidence plus one new fact.** Its only primary page found is the **2017** cycle — "maximum age of 35 years on 31 December 2017", deadline "31 MARCH 2017" — sitting on an official UCAS domain, which is exactly what makes it dangerous: authoritative-looking and nine years stale. Both plausible TWAS URLs for it now return **404**, and it does not appear on TWAS's current PhD fellowship index at all. Third-party aggregators claim a 2027 call is open; the claim could not be traced to a primary source and was not used.
- **A third false claim in the project's own notes was found and corrected.** The thirteenth pass's "Known gaps" said doctoral coverage was "**absent in the USA**". The catalog says otherwise: the USA holds **three** PhD-capable records (`nsf-grfp`, `fulbright-foreign-student`, `knight-hennessy-scholars`). The accurate statement — that the USA has no *PhD-only* record — is now written in its place. This is the same failure mode as the "hero uses CSS animation" claim corrected in the twelfth pass, and the "dark mode is fixed" claim before that: an outstanding-item note is itself a claim, and it inherits no authority from being carried forward.
- **README carried an internal contradiction and it is fixed.** One sentence said "six records carry a single verified closing date"; the next said "Seven". The catalog was counted: **seven** is correct.
- Verified: `npm test` 0 errors / 5 warnings (unchanged); build clean; link probe **71 checked, 0 dead**, the new TWAS URL returning `OK [200]`; browser confirmed **43 opportunities**, the China filter returning **5**, and the new card rendering in both themes.
